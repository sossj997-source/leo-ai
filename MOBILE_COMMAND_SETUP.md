# LEO Mobile Command v2
1. Start: `python run.py`
2. Phone (same Wi-Fi): `https://<LAPTOP_IP>:8000/mobile/pair`
3. Enter the `LEO MOBILE COMMAND TOKEN` printed by the laptop.
4. Pair once, then send commands from the page.
5. Token is stored in the phone browser and the laptop token persists in `%USERPROFILE%\\LEO AI\\mobile_command_token.txt`.
6. Do not expose port 8000 publicly or share the token.
