LEO BROWSER CONTROLLER (NO CDP)

This extension is Leo's preferred browser transport. It controls the already-open
Chrome profile, including normal logged-in sessions, without launching Chrome and
without requiring any CDP command.

ONE-TIME SETUP:
1. Open Chrome.
2. Go to chrome://extensions
3. Turn ON Developer mode.
4. Click Load unpacked.
5. Select this browser_extension folder.
6. Keep the extension enabled.

After that, start Leo normally. No terminal/CDP command is needed.
